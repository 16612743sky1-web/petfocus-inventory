# 쇼핑검색광고 소재·키워드 확정안 + 확인된 사실 (2026-08-04)

> 외부 AI(구글 AI 모드)와의 긴 문답을 검수해 걸러낸 최종본.
> 원 대화의 추천 문구 다수는 금지 표현(1위 주장·비방·"최고"·쫄깃/질겅질겅)·20자 초과로 탈락.
> 규칙 원본: `.claude/skills/ads`, `.claude/skills/marketing`.

## 1. 이 대화에서 확인된 사실 (다음 세션이 다시 묻지 말 것)

- **SKU 구조**: 브랜드 펫포커스. 제품 2종 × 용량 2종(퓨어플레인츄잉 35g/70g, 닭안심회오리츄잉 35g/70g).
  스토어 리스팅은 35g 기준 ×1/×2/×3 묶음이 있어 사용자 기준 6개.
  ⚠️ 70g·건조닭안심 리스팅 포함 전체 개수는 미확인 — 세션 B에서 스토어 화면 기준으로 확정.
- **베스트셀러: 퓨어플레인츄잉 70g.** 사용자가 원하는 주력 구조와도 일치 → 광고 메인 소재.
- **"츄잉"은 소비자 검색어가 아니다.** 실검색어: 강아지껌 / 개껌 / 강아지간식 / 우피껌.
- **덴탈껌 아님** — 상품명·태그·키워드에 덴탈껌·치석 계열 사용 금지(미스매칭 + 표시광고 리스크).
  키워드 탭에 덴탈껌류가 매칭되어 있으면 **제외 키워드로 등록**.
- **제품 특성**: 단단하고 질길 수 있음(개체차). 숨기지 말고 상세페이지에 정직 고지
  (노령견·자견 주의 안내). 단, 광고 문구에는 체감 표현 금지 규칙 적용.
- **브랜드 스토리(사실)**: 원물이 얼리지 않은 생물 상태로 공급됨. 무첨가, 국내산 한우 우피.
- **공개 불가(대표님 결정)**: 공장 내부 사진, 제조원 표기 강조, 성적서 게시 — 당분간 전부 불가.
  → "부모님 공장" 같은 가족·제조원 언급을 공개 카피에 쓰기 전에 반드시 사용자 확인.
- **원칙 확정**: 검색어는 상품명에, 스토리(생물 원물·무첨가)는 확장소재·상세페이지에.
  "얼리지 않은 생물"은 검색용 아님(설득용).

## 2. 상품명 (텍스트 소재) — 퓨어플레인 70g부터 적용

```
펫포커스 퓨어플레인 국내산 한우 우피껌 오래먹는 강아지 개껌 간식 70g
```

- 커버 검색어: 우피껌 / 국내산 우피껌 / 오래먹는 강아지껌(간식) / 개껌 / 강아지간식 / 한우껌 근접.
- "한우"는 수입 우피와의 핵심 차별점이므로 반드시 포함.
- ⚠️ 상품명 변경은 검색 지수에 영향 → **한 번에 확정하고 자주 바꾸지 않는다.**
  등록 전 네이버 자동완성으로 어순 최종 확인(5분).
- 츄잉 단독 표기 금지. 덴탈껌·치석 금지. "오래먹는"은 사용자 승인된 포지셔닝(실검색어이기도 함).

## 3. 확장소재 [추가 홍보문구] 확정 (전부 20자 이내·사실만)

- `국내산 한우 우피 100% 무첨가` (18자)
- `오래 먹는 국내산 한우 우피껌` (16자)
- `얼리지 않은 원물로 만든 우피껌` (17자)
- `원재료 하나, 국내산 한우 우피` (17자)

**금지 재확인**: 1위·누적판매 주장 / 중국산 비방·대기업 비교 / 최고·완벽 / 쫄깃·질겅질겅 등
체감 표현 / 덴탈·치석 / 효능 단정. (원 대화 추천 문구는 대부분 이 중 하나에 걸려 탈락했다.)

## 4. 광고 구조·입찰 실행 순서

1. **소재 3개만 ON**: 퓨어플레인 70g(메인) + 퓨어플레인 35g×1 + 닭안심회오리 35g×1.
   묶음(×2/×3)은 OFF — 묶음 수요는 상세페이지 옵션에서 흡수.
2. **작동 원리**: 쇼핑검색광고 키워드는 직접 등록이 아니라 상품명·카테고리 자동 매칭.
   → 상품명 수정(§2)이 키워드 전략의 선행 조건.
3. **키워드 탭에서**: 틈새(국내산 우피껌, 오래먹는 강아지간식 등)는 입찰 상향 —
   단 **1등 고집 금지, 3위권 목표 + 2~3일 단위 하향식 입찰**(ads 스킬 3단계).
   대형(강아지껌·개껌)은 입찰 하향해 두고 전환 데이터가 쌓이면 유지/제외 판단.
4. **제외 키워드**: 덴탈껌·치석 계열 매칭 발견 시 즉시 제외.
5. 위 판단 전부 **자동 추적 URL 파라미터 ON이 선행 조건.** 꺼져 있으면 그것부터.
6. 확장소재: [쇼핑몰 리뷰] + §3 문구 등록.
