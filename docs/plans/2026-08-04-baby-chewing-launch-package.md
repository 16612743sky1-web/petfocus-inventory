# 퓨어 베이비 츄잉 — 네이버 출시 실무 패키지 + 남은 크레딧 로드맵 (2026-08-04)

> 남은 AI 크레딧을 ①신상품 출시 ②광고 관리 ③방향성 세 가지에 집중 투입하기로 결정.
> 이 문서는 **AI 입력 없이도 실행 가능한 부분을 먼저 확정**해두고,
> 다음 세션에 필요한 준비물을 못박아 크레딧 낭비를 막기 위한 것이다.
> 카피 원본은 `docs/pure-baby-chewing-copy.md`(상세페이지 최종본), 규칙은

## 0. 남은 크레딧 세션 배분 (이 순서대로)

| 세션 | 할 일 | 사용자가 미리 준비할 것 |
|---|---|---|
| **A (완료)** | 출시 패키지 문서화 — 상품명·키워드·썸네일 4안·확장소재·등록 체크리스트 | — |
| **B** | 손익분기 ROAS 확정 + 광고 계정 진단 + 신상품 광고그룹 세팅 지시서 | 아래 §6 준비물 전부 |
| **C** | 소재 반복 루프 1회차 (실제 리뷰 근거 → 앵글 3~5개 → 소재 교체안) | 출시 후 쌓인 구매평·문의 캡처, 소재별 성과 수치 |
| **D (마지막)** | **방향성 전략 문서** — A~C에서 나온 실제 숫자(원가·ROAS·판매) 기반 | B·C 결과 |

출시·광고 데이터가 쌓인 뒤 쓰면 숫자가 있는 전략이 된다. 순서를 바꾸지 않는다.

## 1. 오가닉 상품명 후보 (검색 노출용, 3안)

[핵심 키워드]+[속성]+[대상/용도] 조합, 서로 다른 키워드 5개 안팎. 효능 단정 없음.

1. `퓨어 베이비 츄잉 강아지 우피껌 퍼피 이갈이 국내산 한우 무첨가 수제간식 200g`
2. `강아지 우피껌 퍼피 전용 미니 국내산 한우 무첨가 이갈이 간식 200g`
3. `국내산 한우 우피껌 4개월 퍼피 미니 강아지 수제 간식 200g`

- 추천: **1안** (브랜드명 포함 + 키워드 커버리지 최대).
- ⚠️ **등록 전 5분 작업**: 네이버 검색창에 `우피껌`, `퍼피 간식`, `이갈이` 쳐서
  자동완성·연관검색어를 확인하고, 실제로 뜨는 표현으로 어순·단어를 최종 조정할 것.
  (이번 세션은 네트워크 제한으로 자동완성 확인 불가 — 후보는 지식 기반이다.)

**타깃 키워드 풀**: 강아지 우피껌 / 우피껌 / 퍼피 간식 / 이갈이 간식 / 아기강아지 간식 /
강아지 수제간식 / 소형견 간식 / 강아지 개껌 (상품명·태그·상세 FAQ에 분산 배치)

## 2. 광고 노출용 상품명 (25자 이내, 핵심 키워드 맨 앞)

- 1안: `강아지 우피껌 퍼피 미니 한우` (모바일 잘림 없음)
- 2안: `퍼피 우피껌 국내산 한우 무첨가`
- ⚠️ 오가닉 상품명과 목적이 다르다(ads 스킬 2단계). 광고 소재 등록 시에만 사용.

## 3. 썸네일 4안 (접근 축 분리 — 글자는 편집 툴에서 얹기)

| 안 | 축 | 카피 (12자·2줄 이내) | 비주얼 |
|---|---|---|---|
| ① | 제품 클로즈업 | `첫 우피껌` | 3~6cm 미니 츄잉 클로즈업, 크림 배경 |
| ② | 큰 글자 강조 | `4개월부터` | 제품+큰 타이포, 여백 크게 |
| ③ | 숫자·사실형 | `국내산 한우 100%` | 원물+제품 나란히 |
| ④ | 상황컷 | `이갈이 시기엔` | 퍼피가 물고 있는 촬영컷 |

- 공통: 실제 촬영본 우선, 한글은 별도 레이어, 축소(목록 크기)해서 가독 검증,
  모서리 뱃지 자리 비우기. 디자인 값은 `product-page-system/brands/petfocus.md`만 따른다.
- 광고 전용 이미지는 테두리·빗금으로 대비 추가 가능(오가닉 대표이미지보다 자유도 높음).

## 4. 확장소재 홍보문구 후보 (심사 통과 수준, 효능 단정 없음)

- `첫 껌은 원재료 하나로 시작`
- `이갈이 퍼피 입에 맞춘 3~6cm`
- `국내산 한우 우피만 저온건조`
- `200g 한 봉지 약 70개`
- 리뷰/별점 확장소재는 리뷰 쌓이는 즉시 켠다(비용 0인 개선).
