# 펫포커스 광고 운영 (ads)

네이버 쇼핑검색광고 기준. 카피·이미지의 톤앤매너와 표현 규칙은 `marketing` 스킬을 먼저 따르고,
이 문서는 **광고 운영(설정·예산·입찰·소재 반복)** 만 다룬다.

## 대전제

1. **광고는 깃털, 상품이 화살촉.** 상세페이지·리뷰·상품 자체가 약하면 광고비는 새기만 한다.
   광고 효율이 안 나올 때 입찰가부터 올리지 말고 소재와 상세페이지를 먼저 의심한다.
2. **표시광고법은 전환율의 반대말이 아니라 경계선이다.** 광고 소재는 심사 대상이라
   효능 단정("치석 제거", "구취 치료")은 상세페이지보다 리스크가 더 크다.
   그 경계 안에서 최대한 세게 쓴다 — 규제 회피를 이유로 밋밋하게 쓰는 것도 틀린 선택.
3. **숫자 없이 판단하지 않는다.** 아래 "손익분기 ROAS"를 모르는 상태에서
   "ROAS 300%면 좋은 건가?"를 논하지 않는다.

---

## 시작 전 진단 (매번 새로 확인)

> **수치는 이 문서에 적어두지 않는다.** 네이버 광고 관리 시스템이 항상 최신 원본이고,
> 여기에 복사해두면 낡은 사본이 판단에 끼어든다. 광고 작업을 시작할 때 아래를 직접 확인한다.

**확인할 항목**

| 항목 | 어디서 | 왜 |
|---|---|---|
| 노출 매체 구성 | 노출 지면 보고서 | 파트너 매체·콘텐츠 지면 비중이 크면 광고비 누수 |
| CTR | 광고그룹/소재별 | 상품명·썸네일이 먹히는지 여부 |
| 확장소재 등록 상태 | 소재 설정 | 비어 있으면 광고 면적에서 경쟁사에 진다 |
| 전환 수 (기간별·요일별) | 전환 보고서 | 표본이 결론을 감당하는지 판단 |
| 키워드별 전환 | 자동 추적 파라미터 | 없으면 4단계 자체가 불가능 |

**판단 규칙 (수치가 아니라 이 규칙이 기준)**

- 파트너 매체·콘텐츠 지면 비중이 유의미하면 → **1단계(누수 차단)를 먼저.** 다른 건 그 다음.
- CTR이 쇼핑검색광고 통상 수준에 못 미치면 → **2단계(CTR)가 1순위.**
  이 상태에서 입찰가·요일 최적화를 먼저 손대지 않는다. 기대값이 비교가 안 된다.
- 확장소재가 비어 있으면 → 조건 없이 채운다. 비용이 안 드는 유일한 개선이다.
- 전환 수가 적으면 → 요일·시간대 최적화는 **보류.** 표본 기준은 3단계 참고.
- 추적 파라미터가 꺼져 있으면 → 그것부터 켠다. 키워드 판단은 그 전까지 전부 추측이다.

## 손익분기 ROAS (모든 판단의 기준선)

**목표 ROAS를 감으로 정하지 않는다.** `stock-cost/` 도구의 배치별 실제 원가에서 계산한다.
이게 펫포커스의 구조적 강점이다 — 대부분의 셀러는 자기 제조원가를 모른다.

```
개당 공헌이익 = 공급가(판매가 ÷ 1.1) − 제조원가 − 판매수수료 − 배송비 부담분
손익분기 ROAS = 판매가(VAT 포함) ÷ 개당 공헌이익
```

예시 (숫자는 반드시 실제 값으로 교체):

예시 — 아래 숫자는 **계산 방법을 보여주기 위한 가상값**이다. 실제 판매가·원가와 무관하며,
쓸 때는 전부 실제 값으로 교체한다. (⛔ 실제 판매가를 이 저장소에 적지 말 것 — 공개 배포된다.)

| 항목 | 가상값 |
|---|---|
| 판매가 (VAT 포함) | 18,000 |
| 공급가 (÷1.1) | 16,364 |
| 제조원가 (`stock-cost` 배치 계산) | 5,000 |
| 판매수수료 (약 6%) | 1,080 |
| 배송비 부담분 | 3,000 |
| **개당 공헌이익** | **7,284** |
| **손익분기 ROAS** | **약 247%** |

- **일반과세자이므로 광고비 부가세는 매입세액공제 대상** → 손익분기 계산에 1.1배 할증하지 않는다.
- 이 값 미만 = 팔수록 손해. 이 값 근처 = 본전(단, 리뷰·재구매 확보 목적이면 감수 가능).
- 제품별로 공헌이익률이 다르니 **제품마다 따로 계산한다.** 배송비 부담분이 큰 저가 제품은
  손익분기 ROAS가 훨씬 높게 나온다 — 이런 제품은 애초에 광고 대상에서 빼는 게 맞을 수 있다.

## 1단계 — 비용 누수 차단 (먼저, 무조건)

이건 실험이 아니라 수리다. 한꺼번에 해도 된다.

- **노출 매체 제한**: '네이버 및 검색 포털 매체'만 켜고 파트너 매체·추천/콘텐츠 지면은 모두 끈다.
- **시간대 제한**: 전환이 거의 없는 새벽(00:00~09:00) 노출 Off.
- **자동 추적 URL 파라미터 설정**: 어떤 키워드가 실제 구매로 이어지는지 데이터를 확보한다.
  **이게 없으면 4단계(키워드 집중)를 아예 할 수 없다. 가장 먼저 켠다.**

> ⚠️ **매체를 제한하면 CTR 기준선이 바뀐다.** 저품질 노출이 사라지면서 CTR은 자동으로 오른다.
> 이걸 "썸네일 개선 효과"로 착각하지 말 것. 매체 제한 전후 CTR은 직접 비교하지 않는다.
> 소재 성과 비교는 **매체 설정이 안정된 이후 시점부터** 다시 시작한다.

---

## 2단계 — CTR 개선 (화살촉 다듬기)

CTR이 바닥일 때는 아래 3개 중 무엇이 효과를 냈는지 따질 여유가 없다. 셋 다 한다.
(개별 기여도 분리는 CTR이 정상 범위로 올라온 뒤에 할 일이다.)

### 노출용 상품명
- 핵심 키워드를 **맨 앞에**, 25자 이내로 짧고 명확하게.
  예: `강아지껌 한우우피 닭안심츄잉`
- ⚠️ **오가닉 상품명과 광고 노출용 상품명은 목적이 다르다.**
  `marketing` 스킬의 "키워드 5개 안팎 조합"은 **검색 노출(SEO)** 기준이고,
  광고 소재는 **모바일에서 잘리지 않고 읽히는 것**이 우선이다.
  한쪽을 고치면서 다른 쪽을 망가뜨리지 않는지 확인할 것.

### 썸네일
- 광고 전용 이미지는 오가닉 대표이미지보다 자유도가 높다. 빗금·테두리 강조 활용.
- **경쟁사 목록과 나란히 놓고** 색이 묻히지 않는지 본다. 크림·베이지 팔레트는 브랜드 기준이지만
  목록에서 옆 상품과 같은 톤이면 안 보인다 — 테두리·포인트로 대비를 만든다.
- 나머지(글자 12자 2줄, 뱃지 겹침 위치, 축소 검증)는 `marketing` 스킬의 썸네일 원칙을 따른다.

### 확장소재
- 추가 홍보문구 + 쇼핑몰 리뷰/별점을 **반드시** 켠다. 비워두면 경쟁사 대비 광고 면적에서 진다.
- 홍보문구 예: "스트레스 해소엔 쫀득한 한우우피"
- 효능 단정 금지는 여기에도 그대로 적용된다.
- 광고그룹 유형에 따라 지원되는 확장소재가 다르니 관리 시스템에서 실제 가능한 항목을 확인할 것.

## 3단계 — 예산·입찰

### 하향식 입찰 (Downward Bidding)
1등을 고수하지 않는다. **3위권 노출을 목표**로 2~3일 단위로 입찰가를 5~10%씩 낮추면서
매출이 유지되는 지점을 찾는다. 매출이 꺾이기 시작하는 직전이 최적 ROAS 구간이다.

### 요일 가설 검증 — 여기서 실수하기 쉽다

특정 요일에 전환이 몰려 보일 때(예: 일요일 집중), **그 가설을 검증하는 동안 다른 요일 예산을
건드리면 안 된다.**

> 평일 예산을 깎으면 평일 노출이 줄고 → 평일 전환이 더 줄고 → "역시 일요일이 좋다"는
> 결론이 나온다. 이건 검증이 아니라 **가설을 자기충족적으로 만드는 것**이다.

올바른 순서:
1. 1단계(매체·시간대·추적) 적용 후 설정이 안정될 때까지 며칠 둔다.
2. **예산을 요일 균등하게 유지한 채** 최소 4주 데이터를 쌓는다.
3. 요일별 전환 수를 본다. **요일당 전환이 5건은 넘어야** 편차를 논할 수 있다.
   그 미만이면 4주를 더 쌓거나, 요일 최적화를 포기하고 다른 레버에 집중한다.
4. 4주 뒤에도 해당 요일 우위가 유지되면, 그때 그 요일의 피크 시간대로 예산을 재배분한다.

전환 수가 적을 때는 **요일 최적화보다 CTR 개선의 기대값이 훨씬 크다.** 순서를 지킨다.

## 4단계 — 성과 키워드 집중

**전제: 자동 추적 URL 파라미터가 켜져 있고 데이터가 쌓였을 것.**

- 전환 5건 이상 발생한 키워드만 '효자 키워드'로 인정한다. 1~2건은 우연이다.
- 확실한 전환 키워드('강아지껌' 등)만 담은 **별도 확장 그룹**을 만들어 예산을 집중한다.
  (네추럴조이 등 경쟁사 계정 구조 벤치마킹)
- 전환 0건인데 클릭만 먹는 키워드는 제외 키워드로 등록한다. 이게 누수 차단의 2차전이다.

## 소재 반복 루프 (매달 1회)

소재를 감으로 새로 만들지 않는다. **근거 → 앵글 → 검증**의 순환으로 돌린다.

1. **근거 수집 (grounding)** — 새 소재를 만들기 전에 실제 자료부터 모은다:
   쿠팡·네이버 **구매평에서 보호자가 실제로 쓴 표현**, 문의 내용, 성과 좋은 경쟁사 소재.
   → 각 소재 컨셉이 **어느 리뷰·어느 데이터에서 나왔는지 출처를 남긴다.**
   출처 없이 그럴듯하게 지어낸 문구가 성과가 안 나는 가장 흔한 원인이다.
2. **앵글 분리** — 서로 다른 구매 동기 3~5개를 먼저 정하고, 그 다음에 문구를 쓴다.
   (`marketing` 스킬의 "썸네일 4개 접근 축 다르게"와 같은 원리)
3. **성과 기반 교체** — 한 달 뒤 상위/하위 소재를 갈라 **공통 패턴**을 찾는다.
   진 소재를 버리고, 이긴 소재의 패턴을 변형한 새 앵글을 넣는다.
   개별 소재의 승패가 아니라 **패턴**을 뽑아내는 게 핵심이다.

## 하지 말 것

- 손익분기 ROAS를 모르는 채로 목표 ROAS 정하기
- 추적 파라미터 없이 키워드 예산 조정하기 (근거가 없다)
- 1~2주 데이터로 요일·시간대 패턴 확정하기
- 검증하려는 변수(요일)에 예산을 편향시켜 놓고 검증했다고 하기
- 매체 설정 변경 전후의 CTR을 같은 기준으로 비교하기
- 효율 안 나올 때 입찰가부터 올리기 (소재·상세페이지 먼저)
- 광고 소재에 효능 단정 표현 쓰기 (심사 리스크 + 표시광고법)

## 작업 체크리스트

- [ ] 광고 관리 시스템에서 현재 수치를 직접 확인했는가 (문서의 옛 숫자로 판단하지 않기)
- [ ] 해당 제품의 손익분기 ROAS를 `stock-cost` 원가로 계산했는가
- [ ] 자동 추적 URL 파라미터가 켜져 있는가
- [ ] 제안한 변경이 "수리(1단계)"인지 "실험(3단계)"인지 구분했는가
- [ ] 실험이라면, 검증하려는 변수 외의 조건을 고정했는가
- [ ] 표본이 결론을 내리기에 충분한가 (요일 판단 = 요일당 전환 5건 이상)
- [ ] 소재 컨셉에 근거 출처(리뷰·성과 데이터)를 남겼는가
- [ ] 광고 문구에 효능 단정·과장 표현이 없는가 (`marketing` 스킬 기준)
