# final-smartstore — 스마트스토어 업로드 최종본 (소스 기록)

원본 산출물은 Drive `PETFOCUS_HQ/final-smartstore/`에 있다(슬라이스 11장 + styles.css +
render-smartstore.js + assets). 이 폴더의 `index.html`은 **2026-08-04 대조·개선분을 반영한
소스 기록**이며, Drive 쪽과 이 파일이 다르면 **이 파일이 최신 기준**이다.

## 2026-08-04 반영분 (Drive 원본 대비 추가된 것)

1. **약 72개** — 봉지 구성 수량(실측 확정값)을 bag 섹션에 명기. 원본엔 개수 언급이 없었다.
2. **자체 급여 테스트 서사** — guide 섹션 도입부. 과정 서술만, 안전 단정 없음.
3. **실제 후기 캡처 섹션(real-reviews)** — 대표 지시. 캡처 슬롯 4개,
   원본은 Drive `리뷰캡쳐사진_260804.zip`. 마스킹·원본 그대로·기존 제품 후기 명시 필수.
4. **FAQ 3문항** — AI 쇼핑 검색 대응(FINAL_COMPARISON §11 근거를 이 빌드에도 적용).

새 섹션의 CSS는 `<head>`의 인라인 `<style>`에 있다 (styles.css는 Drive 관리라 건드리지 않음).

## ⚠️ 대표 확인 필요 (미결)

- **컨셉 불일치**: `FINAL_COMPARISON.md`는 **Concept B(고대비 모바일형) 추천**인데,
  이 최종 빌드는 **Concept A 계열(크림·편집형)**이다. 의도된 선택인지 확인할 것.
- **"부모님이 운영하는 원물 가공 공장" 문구**(source 섹션) — 가족 정보 공개 여부는 대표 결정 사항.
- 판매가·배송·교환반품 정보, 라벨 기준 급여량 → 스토어 등록 정보에서 입력 (본문 미기재 원칙).
